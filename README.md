# Radhakrishna Jonnavittula — Personal Website

Source code for my academic and technical portfolio, published through GitHub Pages at **[rjonnavittula.github.io](https://rjonnavittula.github.io/)**.

I am a Computer Science student at Penn State University interested in AI agents, machine learning, computer vision, LLM security, and systems engineering.

## Projects and research

- **[H.I.V.E.](https://github.com/rjonnavittula/H.I.V.E.)** — private, multi-project ecosystem for local AI assistants, productivity, and self-hosted applications.
- **[HIVE study-planning backend](https://github.com/rjonnavittula/hive-scholar)** — self-hosted task/course management, Canvas integration, scheduling feasibility, and retrieval-grounded learning components.
- **[HackPSU25](https://github.com/rjonnavittula/HackPSU25)** — a command-line local AI assistant using Ollama, conversation history, retrieval, and tools.
- **[InjecAgent fork](https://github.com/rjonnavittula/InjecAgent)** — fork of [UIUC Kang Lab's InjecAgent](https://github.com/uiuc-kang-lab/InjecAgent), used in prompt-injection research and evaluation.

Research interests include multimodal learning and behavioral analysis, eye-tracking, prompt injection, and agent evaluation.

## Website development

This site uses Jekyll and GitHub Pages. The content is configured through `_config.yml`, `_pages/`, `_posts/`, and the other Jekyll collections.

For local development, install Ruby, Bundler, and dependencies from the repo's `Gemfile`, then run:

```bash
bundle install
bundle exec jekyll serve
```
